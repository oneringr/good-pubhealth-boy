# Good Pubhealth Boy

用于 `https://virlab.swmu.edu.cn/` 的 Chrome 扩展。第一个功能是在插件弹窗中填写账号密码，然后自动登录虚拟仿真实验平台。

## 使用自动登录

1. 点击扩展图标，填写账号和密码。
2. 点击「保存并登录」。插件会打开或使用当前网站标签页，填写登录表单并提交。
3. 保存后，新标签页访问网站也会自动登录。一次失败后不会在同一标签页反复尝试；可再次点击「保存并登录」重试。
4. 不再使用时，点击「清除保存的账号密码」。

账号密码保存在当前浏览器配置的 `chrome.storage.local` 中，未额外加密。测试账号没有写入项目文件。

## 查看课程答案

打开课程学习页后，右下角会出现放大镜按钮。点击按钮可查看当前 H5 课程已经加载到浏览器的题干与答案。按住答案窗口的标题栏可拖动窗口；窗口不会被拖出浏览器可视区域。选择题按动画内部选项顺序显示正确项序号；小鼠致畸试验课程还显示完整选项文字，并用蓝色标出正确项。该课程的选项是动画中的矢量图形，文字由课程画面核对后录入。

答案窗打开时，插件还会在当前动画的正确可点击选项旁显示蓝色勾号。已在小鼠致畸试验、空气污染采样和艾滋病传播与防治课程验证，支持单选与多选；切换题目或动画章节后会更新，关闭答案窗即清除标记。这种方式通过动画控件定位选项，其他使用相同 CreateJS 控件结构的课程无需逐题录入选项文字。动画不提供可点击选项的填空题、操作题不会出现勾号。

填空题显示脚本中的判分条件。当前识别器支持 `Tigan.txt` 的多个题干分组，以及 `right_arr`、`jfarr`、`jf_num` 等 CreateJS 判分格式。脚本中没有明确判定值的题目会显示「暂未识别到答案」。查看答案和动画标记不会自动提交成绩。

## 直接提交成绩

课程页右下角放大镜左侧是红色上箭头按钮。点击后填写 0–100 的整数成绩和用时（分钟）；有多个实验部分的课程还需选择实验项目。点击「提交成绩」后，插件使用课程自身的 `ScoreUpload` 流程上传，保留课程当前已记录的步骤数据。弹窗显示发送结果；最终是否录入以平台的课程成绩记录为准。测试时只拦截上传接口核对数据，没有写入测试成绩。

## 启动开发浏览器

在 PowerShell 中运行 `./open-dev-browser.ps1`。脚本使用指定的 Chrome for Testing、独立的 `.chrome-profile/` 配置、`--no-proxy-server` 直连网络，并加载本目录作为扩展程序，最后打开实验平台。站点会跳转到 `/mengoo/`。可用 `-Url` 参数打开指定课程地址。

## 手动加载

1. 用 Chrome 打开 `chrome://extensions/`。
2. 开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择本目录 `D:\code\good-pubhealth-boy`。
4. 修改文件后，在扩展程序页面点击「重新加载」。

开发专用 Chrome 配置保存在 `.chrome-profile/`，不会提交到 Git。
